# 차계부 — 제출 시연 대본 초안

작성일 2026-11-11. 60~90초는 내부 편집 목표다. 녹화 전이며 실제 영상 길이·완성도 확인과 구분한다.

## 촬영 전 조건

- 최종 서명 release APK 설치·음성 서버 연결 검증 후 촬영한다. 개발용 Mac relay를 사용했다면 영상에도 그 조건을 명시한다.
- Pleos Connect Emulator 2.1.0, 2560×1440 전체 화면 기준. 앱 표시 영역을 잘라도 차량 맥락이 남도록 구성한다. 실차 영상으로 표현하지 않는다.
- 별도 데모 환경의 가상 지출을 사용한다. 사용자의 실제 기록을 지우지 않는다. 기존 기록을 이용하면 가짜 ‘0원부터’ 흐름으로 편집하지 않는다.
- OS 알림·개인 이름·계정·키·서명·연락처를 촬영하지 않는다. 첫 음성 전송 안내를 생략하거나 사용자 확인 없이 음성을 전송하지 않는다.
- P→다른 기어 전환 장면은 실제 SDK 입력을 바꿔 확인한 경우에만 포함한다. Fake 테스트 영상을 실제 차량 연결로 설명하지 않는다.

## 80초 구성

| 시간 | 실제 화면/동작 | 자막·내레이션 초안 |
| --- | --- | --- |
| 0~8초 | 차계부 홈, ‘에뮬레이터 시연 · 데모 지출’ 표기 | 카드값과 별개로, 이번 달 내 차에 쓴 돈은 얼마일까요? |
| 8~15초 | P 상태 확인, 새 기록 선택 | 지출 직후, 안전하게 주차한 상태에서 기록합니다. |
| 15~30초 | 마이크 시작 → “주유 삼만 원” → 끝내기 → 실제 응답 대기 | 한마디로 금액과 항목을 입력합니다. 인식 결과를 확인한 뒤 저장합니다. |
| 30~40초 | 주유·30,000원 확인 → 저장 → 홈 합계·그래프 | 기록한 지출이 월 합계와 항목별 비중에 반영됩니다. |
| 40~54초 | “주차 삼천 원” → 확인·저장 → 두 항목 그래프 | 주유와 주차 등 차량 관련 지출을 한곳에서 확인합니다. |
| 54~65초 | 내역 수정 진입, 금액 수정 후 취소 → 합계 유지 | 잘못된 기록은 고칠 수 있고, 저장 전 취소하면 반영되지 않습니다. |
| 65~73초 | 검증된 경우 실제 SDK 기어 전환·입력 제한. 미검증이면 직접 입력 대안 장면 | P 상태가 확인될 때만 입력합니다. / 음성 연결이 어려우면 직접 입력할 수 있습니다. |
| 73~80초 | 월 요약과 앱명 | 차 안에서 잊기 전에 기록하는, 차계부. |

인식 대기 시간을 줄여 편집하면 ‘대기 구간 단축’ 표시를 넣는다. 첫 시도 실패를 성공률 통계로 숨기거나 녹화본을 실시간 시연이라고 표시하지 않는다. 금액·합계는 실제 데모 DB 결과와 맞춘다.

## 촬영 후 검사

- [ ] 영상의 APK 버전/커밋과 제출 파일이 일치.
- [ ] 실제 마이크 발화와 앱 결과를 함께 확인 가능.
- [ ] 확인 후 저장, 합계·범례가 읽힘. 주요 동작이 잘리거나 자막에 가리지 않음.
- [ ] 가상 기록·에뮬레이터·편집 대기 표시가 사실과 맞음.
- [ ] 무음 재생에서도 핵심 흐름을 자막으로 이해 가능.
- [ ] 계정 로그아웃/다른 환경에서도 링크 재생 가능.
- [ ] 최종 영상 링크를 양식 7번과 제출 메일 초안에 반영.

현재 완료: 대본. 미완료: 최종 APK, 녹화, 편집, 게시·재생 확인.
