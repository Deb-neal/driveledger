# Phase 2 — 지출 기록·보관·월 집계

후속 UIUX 개선과 큰 글씨 검증은 [화면 개선 기록](uiux-validation-2026-11-07.md)을 참조한다. 아래는 최초 Phase 2 구현 당시의 기록이다.

작업일: **2026-11-07 KST**. 개발용 Pleos ARM64 에뮬레이터에서 검증했다. 음성→지출 화면 연결, 실제 사람 발화 정확도 및 실차 검증 완료를 의미하지 않는다.

## 구현

- 런처를 차계부 홈으로 전환했다. 기존 차량·음성 진단은 비공개 `ProbeActivity`로 보존했다.
- 오늘의 단일 지출 문장을 제한된 규칙으로 읽고 금액·항목을 확인·수정·취소한다. 직접 숫자 입력도 가능하다.
- 불분명한 금액과 항목은 채우지 않는다. 범위, 음수/환불, 계산식, 복수 지출, 과거 날짜를 자동 처리하지 않는다.
- SQLite에 날짜·항목·원 단위 금액을 보관한다. 원문 문장과 음성은 DB에 저장하지 않는다. 저장 중 버튼 차단과 기록 UUID로 중복 삽입을 막는다.
- 월 총액·항목별 합계·최근 20건을 보여준다. 합계는 해당 월 전체 내역 기준이다. 이전/다음 달 이동, 저장한 내역 수정·삭제도 구현했다.
- 수정·삭제는 버전을 비교하여 오래된 화면이 최신 기록을 덮어쓰지 못하게 한다. 저장 실패 시 입력을 유지하고 재시도 안내를 표시한다.
- 입력 중 화면이 재생성되어도 날짜·금액·항목·문장·기록 식별자를 복원한다.
- 넓은 차량 창에서는 두 열, 좁은 창에서는 한 열로 구성한다. 기본/야간 색상, 시스템 글씨 확대, 64dp 이상 버튼과 접근성 라벨을 적용했다.

## 자동 검사

명령:

```sh
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug
```

- 빌드 성공, **단위 테스트 16개 통과**. 금액 파서 7개, 월 집계 4개, 기존 정책·PCM 5개.
- Lint **오류 0, 경고 17**. 기존 진단 문자열, 아이콘, 백업 정책, targetSdk/Gradle 알림, 미사용 색상 등은 남아 있다. release 승인 결과가 아니다.
- `ExpenseStoreTest`: 별도 테스트 DB에서 중복 삽입/다른 내용 재시도 거부, 10/31·11/30·12/1 월 경계, 금액·항목 수정, 오래된 수정·삭제 거부, DB 재열기·삭제 후 집계를 검증했다.
- `LedgerFlowTest`: “오늘 주차비 삼천 원” → 3,000원 확인 → 0원 저장 거부 → 4,500원 수정 → 화면 재생성 후 입력 유지 → 연속 저장 클릭 → 한 건만 저장 → 5,500원 수정 → 새 입력 취소 → 기존 기록 삭제를 실제 화면에서 검사했다. 테스트가 만든 기록만 정리한다.
- `MicrophoneLifecycleTest`, `OfflineSpeechTest`도 새 Activity 구성에서 통과했다. 호스트 마이크가 비활성화된 환경의 회귀 검사이며 사람 목소리를 테스트한 것이 아니다.
- 텍스트 색상 조합의 명암비를 계산했다. 밝은/어두운 테마 모두 검사한 본문 조합이 4.5:1 이상이다.
- 시스템 전환이 끝난 뒤 야간 모드 단독으로 재검사했다. 홈·확인·오류 화면의 실제 캡처를 확인했고 잘림 없이 표시됐다. 글씨 확대와 야간 모드의 동시 조합은 아래 제약으로 구분한다.

개발 중 “약 7만원”의 ‘약’을 놓치는 파서 테스트 실패를 수정했다. 또 이전 테스트 APK를 잘못 실행해 시각 검사 클래스를 찾지 못한 실행이 있었고, 새 APK 설치 후 재실행하여 통과했다. 최종 결과는 아래 산출물에 기록했다.

## 프로세스 재실행 검사

자동 화면 조작으로 빈 에뮬레이터 앱에 **기타 / 2,468원**을 저장했다. `am force-stop --user 10`으로 앱 프로세스를 종료하고 다시 실행했을 때 2,468원이 유지됐다. 이어서 화면에서 삭제하고 0원으로 복귀한 것을 확인했다. 실제 지출을 사용하지 않았으며 검사 기록은 남기지 않았다.

## 남은 제약과 다음 단계

- 제품의 기록 화면은 현재 텍스트 입력이다. 음성 인식은 분리된 진단 화면에서 동작한다. Phase 3에서 실제 마이크→확인→저장 연결과 발화 정확도를 검증한다.
- 현재 제품 화면의 주차 안내는 설명 문구다. 차량 상태에 따른 입력 차단은 아직 연결되지 않았으므로 운행 중 사용할 완성품이 아니다. Phase 3에서 상태 미상/주행 시 입력 제한과 오디오 포커스를 처리한다.
- 차량 주행거리의 단위·조회 시각 검증 및 기록 첨부도 Phase 3에 남아 있다.
- 기록은 기기 시간대의 오늘 기준이다. 에뮬레이터가 실행 옵션의 시간대를 덮어써 `cmd alarm set-timezone Asia/Seoul`로 맞췄다.
- 최근 20건을 넘는 같은 달 내역을 펼치는 기능, 과거 날짜 신규 입력, 내보내기/동기화는 미구현이다. 앱 삭제/데이터 초기화 시 복구 기능이 없다.
- 기기 저장 공간 부족·실제 프로세스 종료와 쓰기의 동시 발생 등 모든 장애 상황을 검증한 것은 아니다. 실제 사람의 접근성/사용성 평가도 남아 있다.
- 야간 모드와 글씨 1.3배를 동시에 바꾸자 Pleos 시스템 화면이 재시작되어 초기 캡처에 시스템 로딩 화면이 찍혔다. 재시도 중 테스트 대상 프로세스도 사라져 해당 실행을 중단했다. `unverified-*-dark-large.png`는 앱 UI의 검증 근거가 아니며, 큰 글씨 조합의 실제 화면 확인은 남겨 두었다. 기존 설정으로 복구했다.
- release 서명·설치, 실제 시연 영상·공식 기획서·원격 저장소·제출은 아직 진행하지 않았다.

현재 단계는 여기서 마무리하고, 다음 작업은 Phase 3 준비 및 실제 사용자 발화 확인이다.
