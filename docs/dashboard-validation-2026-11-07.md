# 차계부 — Financy 레퍼런스 대시보드 검증

2026-11-07. 사용자가 제공한 Financy Finance Dashboard 이미지의 밝은 표면, 파란 주요 행동, 상단 요약, 도넛과 내역 구성을 실제 Android Views 앱에 적용했다. 기존 코드/DB 위에서 구현했으며 원본 Figma 소스나 외부 차트 라이브러리는 가져오지 않았다.

## 변경

- 상단: 선택한 월, 기록 시작 버튼, 차량 지출 합계·기록 건수·최대 지출 항목.
- 하단: 전체 월 기록을 집계한 도넛/범례와 최근 20건 내역. 목록을 20건으로 제한해도 그래프·합계는 전체 기록을 사용한다.
- 8개 항목의 색상은 고정. 범례는 항목·금액·비율을 모두 표시하고 접근성 설명을 제공한다. 0건은 안내, 한 항목은 전체 원, 작은 비중은 임의로 확대하지 않는다.
- 비율은 소수 첫째 자리 반올림으로 합이 100%와 조금 다를 수 있음을 화면에 알린다. 금액은 계속 정수 원 단위로 계산·보관한다.
- 낮/밤 팔레트와 입력 화면 색상을 함께 변경했다. IBM Plex Sans KR·공통 글자/간격/모서리·입력 상태 규칙은 유지한다.
- 기존 수정·삭제·취소·초안 복원·중복 저장 방지 흐름과 DB 스키마는 유지한다.

## 검증 결과

- `assembleDebug`, `assembleDebugAndroidTest`, `testDebugUnitTest`, `lintDebug` 성공.
- 단위 테스트 20개 통과. 추가 4개는 빈 달, 20건 초과 전체 집계, 최대 금액 8개/동률 정렬, 단일 항목 및 작은 비중을 검증한다.
- Lint 오류 0 / 경고 16. 차트는 XML로 inflate하지 않는 데이터 기반 View이므로 ViewConstructor 경고만 이유를 적어 억제했다. 나머지 경고는 기존 target SDK·백업·아이콘·진단 화면 문구 등의 항목이다.
- Pleos 2.1/API 34 ARM64, 2560×1440의 앱 영역 1682×1210: 기본 UI 회귀/시각 검사 2개 통과. 저장·중복 클릭·초안 재생성·수정·취소·삭제·오류 수정과 처리 중 상태를 확인했다.
- 야간 + 실제 fontScale 1.3에서 시각 검사 1개 통과. 8 × 999,999,999원 = 7,999,999,992원의 한 줄 표시·말줄임 없음·측정 폭, 도넛의 전체 비중을 assertion으로 확인했다. 긴 범례/목록은 스크롤된다.
- 20개 낮/밤 문자 색상 조합 명암비 4.72:1 이상. `artifacts/dashboard/contrast.json`.
- 기본·야간 홈/입력/오류와 빈 상태의 실제 캡처를 확인했다. `artifacts/dashboard/`의 `*-detail.png`는 앱 부분만 자른 실제 캡처이며 원본도 함께 있다.
- 모든 촬영 데이터는 임시 ID로 생성하고 테스트 종료 시 해당 ID만 제거한다. Pleos DB 최종 상태 0건/0원 확인. 193,000원은 예시이며 사용자 지출이나 제품 기본값이 아니다.

## 환경과 범위

Pleos의 해상도 override로 작은 창을 만들려 했으나 실제 Activity 폭이 줄지 않아 compact assertion이 실패했다. 이 시도는 검증 통과로 계산하지 않는다. 원래 2560×1440, 낮 모드/fontScale 1.0으로 복원했다. 별도 Android Phone API 36.1 AVD에서도 검사를 시도했지만 시스템 화면이 앱을 가려 캡처 대상 패키지 검증에 실패했다(`instrumentation-phone.txt`). 휴대폰 세로 화면은 검증 완료로 계산하지 않는다. 특히 좁은 폭에서 긴 금액과 항목/날짜가 함께 보이는지는 추가 확인이 필요하다.

독립 디자인 검토에서 차량용 기본·입력·오류·야간 큰 글자·빈 상태 캡처와 관련 코드를 확인했고, 차량 화면의 수정 필수 시각 결함은 없었다. 이 검토는 테스트를 별도로 재실행한 결과가 아니며 휴대폰·키보드·접근성 탐색·실차 조작까지 검증한 것은 아니다.

날짜는 기기 로컬 시간을 따르며 촬영 시 Pleos AVD의 timezone은 America/Los_Angeles였다. 따라서 예시 날짜가 한국 기준 작업 날짜와 다를 수 있다. 기기의 시간대를 임의 변경하지 않았다.

실차, 실제 발화, 차량 상태에 따른 입력 제한, release 서명·설치·제출은 이번 UI 작업 범위 밖이다.
