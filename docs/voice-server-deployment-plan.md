# 제출용 음성 서버 준비안 — 2026-11-11

상태(11/13 갱신): 사용자 Render 가입 완료. 인증·영속 사용량 상한을 갖춘 서버 코드, render.yaml, Android HTTPS 연결 경로와 동의 안내를 구현했다. 로컬 검사를 통과했으며 실제 유료 생성·배포·최종 release 설치는 아직 하지 않았다. [설정 안내](../server/README.md).

## 추천 구성

Render Hobby 워크스페이스의 512MB 유료 Web Service 1개와 영속 디스크 1GB. 별도 도메인은 구입하지 않고 제공되는 HTTPS 주소를 사용한다. 기존 Python 음성 변환 로직을 재사용하되, 개발용 `local-voice-relay.py`를 그대로 인터넷에 노출하지 않는다.

- 서버 인스턴스: 월 $7부터, 공식 가격표의 0.5 CPU / 512MB.
- 영속 디스크: $0.25/GB·월, 1GB 사용 시 기본 합계 월 약 $7.25.
- OpenAI API, 세금·환율·초과 트래픽 등은 별도. 월 금액은 한 달 운영 기준이며 실제 청구는 사용 시간과 배포 화면 견적을 다시 확인한다.
- 무료 인스턴스는 15분 무요청 시 중지되고 재시작에 약 1분이 걸릴 수 있어, 현재 앱의 음성 응답 제한 시간에 맞지 않는다.
- 음성 파일·인식문·지출 DB를 서버 디스크에 저장하지 않는다. 디스크는 재시작 후에도 유지되는 요청 수/기간별 제한과 인증 관리에만 사용한다.

## 구현할 경계

1. 앱 → HTTPS 서버 → OpenAI. OpenAI 키는 서버 환경변수에만 둔다.
2. 심사용 접근 토큰과 서버 측 전체/기간별 요청 상한을 둔다. 공개 APK 속 공통 토큰은 추출 가능하므로 비밀키처럼 신뢰하지 않는다. 전체 상한은 디스크에 원자적으로 보관하며 서버 재시작으로 초기화되지 않게 한다.
3. 최대 8초·16kHz 모노 PCM16 WAV만 허용하고 크기·형식·무음을 확인한 뒤 유료 API를 호출한다. 동시 요청 수와 시간 제한을 둔다. 타임아웃 시 자동 재시도로 과금하지 않는다.
4. 음성·텍스트·토큰·키를 요청 로그/오류에 쓰지 않는다. 상태와 실패 유형만 기록한다. 지출 기록은 계속 앱 안에만 보관한다.
5. 앱 첫 사용 안내의 ‘Mac 개발 서버’를 실제 배포 경로에 맞게 고친다. 연결 실패 시 직접 입력 가능하며 인식 결과를 자동 저장하지 않는다.
